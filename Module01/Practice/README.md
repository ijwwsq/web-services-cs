# Практическая работа 1. GamesApi

## Задание 1

Предметная область: игры. Основной ресурс: `Game`.

| Поле | Тип | Описание |
|---|---|---|
| Id | int | идентификатор |
| Title | string | название |
| Genre | string | жанр |
| Developer | string | разработчик |
| ReleaseYear | int | год выхода |
| Price | decimal | цена |

## Задание 2

| Операция | Метод | URL | Коды |
|---|---|---|---|
| Получить все игры | GET | `/api/games` | 200 |
| Получить игру по id | GET | `/api/games/{id}` | 200, 404 |
| Добавить игру | POST | `/api/games` | 201, 400 |

400 возвращается, если не заполнено название, жанр или разработчик, либо год или цена вне допустимого диапазона.

## Задание 4

### Что такое Web API?
Сервис, с которым программы общаются по HTTP. Отправляешь запрос на адрес вроде `/api/games` и получаешь данные в JSON.

### В чём разница между HTTP Request и HTTP Response?
Request отправляет клиент: метод, адрес и данные. Response возвращает сервер: статус-код и результат.

### Для чего используется GET?
Чтобы получить данные, например список игр или одну игру.

### Для чего используется POST?
Чтобы отправить на сервер новые данные, например добавить игру.

### Что означают 200 OK и 404 Not Found?
200 значит, что всё прошло успешно. 404 значит, что такого ресурса нет.
