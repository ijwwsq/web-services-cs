# Лабораторная работа 1. CoursesApi

Web API для списка учебных курсов, данные хранятся в памяти.

- `GET /api/courses` - все курсы (200)
- `GET /api/courses/{id}` - курс по id (200, 404)
- `POST /api/courses` - добавить курс (201)
- `PUT /api/courses/{id}` - изменить курс (204, 404)
- `DELETE /api/courses/{id}` - удалить курс (204, 404)

## Почему Web API должен возвращать 404, а не пустой объект?

Если вернуть 200 и пустой объект, клиент решит, что курс нашёлся, просто у него пустые поля. По коду 404 сразу видно, что такого курса нет, и клиенту не надо самому разбираться, что ему пришло. Это стандарт HTTP, его понимают все клиенты одинаково.

## Контрольные вопросы

### 1. Что такое Web API?
Интерфейс, через который программы обмениваются данными по HTTP. Клиент отправляет запрос на адрес, сервер отвечает данными, обычно в JSON.

### 2. Чем Web API отличается от обычной веб-страницы?
Страница возвращает HTML, который браузер показывает человеку. API возвращает данные, которые обрабатывает другая программа.

### 3. Что такое клиент-серверная архитектура?
Клиент отправляет запросы, сервер их обрабатывает и отвечает. Данные и логика находятся на сервере, клиентов может быть много.

### 4. Что такое HTTP request?
Запрос от клиента к серверу. В нём есть метод, URL, заголовки и иногда тело с данными.

### 5. Что такое HTTP response?
Ответ сервера на запрос. В нём есть статус-код, заголовки и тело с данными.

### 6. Что такое endpoint?
Адрес и метод, по которым доступна конкретная операция, например `GET /api/courses/1`.

### 7. Для чего используется HTTP GET?
Для получения данных. На сервере при этом ничего не меняется.

### 8. Для чего используется POST?
Для создания новой записи. Данные передаются в теле запроса.

### 9. В чём отличие PUT от POST?
POST создаёт новый объект, PUT изменяет существующий по id. Повторный PUT даст тот же результат, а повторный POST создаст ещё одну запись.

### 10. Для чего используется DELETE?
Для удаления объекта, например `DELETE /api/courses/1`.

### 11. Что означает HTTP Status Code 200?
OK, запрос выполнен успешно.

### 12. Что означает 201?
Created, новый объект создан.

### 13. Что означает 204?
No Content, запрос выполнен, но тело ответа пустое. Обычно так отвечают на PUT и DELETE.

### 14. Что означает 404?
Not Found, запрошенный ресурс не найден.

### 15. Что такое JSON?
Текстовый формат данных из пар ключ-значение и массивов. Его легко читать и легко разбирать в любом языке.

### 16. Что делает атрибут [HttpGet]?
Помечает метод контроллера как обработчик GET-запросов. В нём можно указать шаблон пути, например `[HttpGet("{id}")]`.

### 17. Для чего используется [Route]?
Задаёт адрес контроллера или метода. `[Route("api/[controller]")]` у `CoursesController` даёт `api/courses`.

### 18. Что делает ControllerBase?
Это базовый класс для API-контроллеров. Из него берутся методы `Ok()`, `NotFound()`, `NoContent()`, `CreatedAtAction()` и доступ к запросу. Поддержки View в нём нет, для API она не нужна.

### 19. Что такое Swagger?
Инструмент, который строит документацию по API и страницу, где можно отправлять запросы прямо из браузера.

### 20. Почему Web API удобно использовать для взаимодействия нескольких информационных систем?
HTTP и JSON поддерживаются в любом языке, поэтому системы на разных технологиях могут обмениваться данными, не зная, как устроены друг у друга. Систему можно менять как угодно, пока формат запросов и ответов остаётся прежним.
