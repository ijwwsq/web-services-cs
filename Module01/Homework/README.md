# Домашняя работа 1. WebApiLab1

| Метод | Endpoint | Назначение |
|---|---|---|
| GET | `/api/students` | получить список студентов |
| GET | `/api/students/{id}` | получить студента по id, 404 если нет |
| POST | `/api/students` | добавить студента |

## Контрольные вопросы

### 1. Что такое Web API?
Интерфейс приложения, к которому обращаются по HTTP. Клиент отправляет запрос, сервер возвращает данные, обычно в JSON.

### 2. Что такое HTTP-запрос?
Сообщение от клиента к серверу: метод, URL, заголовки и иногда тело с данными.

### 3. Что такое HTTP-ответ?
Сообщение от сервера клиенту: статус-код, заголовки и тело с результатом.

### 4. Для чего используется метод GET?
Для получения данных, например `GET /api/students`.

### 5. Для чего используется метод POST?
Для добавления новых данных. Они передаются в теле запроса.

### 6. Что означает код 200 OK?
Запрос выполнен успешно.

### 7. Что означает код 404 Not Found?
Ресурс не найден, например студента с таким id нет.

### 8. Что такое JSON?
Текстовый формат данных, например `{ "name": "Ayan", "age": 20 }`.

### 9. Что такое endpoint?
Адрес и метод, по которым доступна операция, например `GET /api/students/{id}`.

### 10. Для чего используется Swagger?
Чтобы смотреть документацию по API и тестировать запросы прямо из браузера.
